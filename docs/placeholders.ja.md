# プレースホルダーガイド

以下のマーカーを HTML またはメール本文に書き込むと、プロジェクトのデプロイ時またはメール送信時にプラットフォームが実値へ置き換えます。

2 つのセットは**互換ではありません**：

- **プロジェクトのランディングページ**用マーカーをメールに書かない
- **メール**用マーカーをプロジェクト HTML に書かない

ページライブラリ / ページビルダーのプレビューでは、プロジェクト用プレースホルダーは**置換されません**。**ページ制作**で HTML をアップロードまたはミラーし、プロジェクト作成時にそのページを選び、ビルド/起動してください。

---

## 1. プロジェクトのランディングページ（プロジェクト）

プロジェクトにアップロードする HTML で次のプレースホルダーを使います。

| プレースホルダー | 用途 | 記入の目安 |
|------------------|------|------------|
| `{{SUBMIT_URL}}` | フォーム送信 URL | **推奨。** フォームの `action` または API URL に使う |
| `{{REDIRECT_URL}}` | 送信後の元サイト URL | 任意。プロジェクトの「元 URL」欄から取得 |
| `{{QR_RELAY_URL}}` | ライブ QR 画像 URL | スキャンログイン UI 向け。プロジェクトで QR リレーをバインド |
| `{{QR_RELAY_IMG}}` | QR の完全な `<img>` タグ | 同上。自分で `img` を書かず、このトークンを挿入 |

### 例

```html
<!DOCTYPE html>
<html lang="ja">
<head>
  <meta charset="utf-8" />
  <title>ログイン</title>
</head>
<body>
  <h1>サインイン</h1>

  <form method="POST" action="{{SUBMIT_URL}}">
    <input name="username" placeholder="ユーザー名" required />
    <input name="password" type="password" placeholder="パスワード" required />
    <button type="submit">ログイン</button>
  </form>

  <!-- スキャンログイン：QR フィッシングでリレーを作成し、プロジェクトでバインド -->
  <h2>スキャンしてサインイン</h2>
  {{QR_RELAY_IMG}}

  <!-- または自分で画像タグを書く：
  <img src="{{QR_RELAY_URL}}" alt="スキャンしてサインイン" width="240" height="240" />
  -->

  <p><a href="{{REDIRECT_URL}}">公式サイトへ戻る</a></p>
</body>
</html>
```

### 手順（QR を使う場合）

1. ワークベンチ → **QR フィッシング**：リレーを作成し、ローカルのキャプチャスクリプトを実行  
2. **プロジェクト**：作成または編集し、ページ制作のページを選び、「QR リレー」で当該リレーを選択  
3. プロジェクトをビルドして起動  
4. プロジェクト URL を開き、送信 URL と QR 画像が表示されることを確認  

### 注意

- 元 URL の変更、リレーの付け替え、公開スラッグのローテーション後は、プロジェクトを**再ビルドまたは再起動**してください。  
- リレー未バインド、またはリレー一時停止時は、`{{QR_RELAY_URL}}` / `{{QR_RELAY_IMG}}` は空になります。  
- `{{QR_RELAY_IMG}}` は完全なタグです。単独の行に置き、`src="{{QR_RELAY_IMG}}"` と書かないでください。

## 2. メール本文（ワークベンチ → メール送信）

キャンペーン本文では次のプレースホルダーを使います。送信時に受信者ごとに置換されます。

| プレースホルダー | 用途 | 記入の目安 |
|------------------|------|------------|
| `{{email}}` | 現在の受信者アドレス | 挨拶などに使用 |
| `{{click_url}}` | 追跡可能なクリック URL | **推奨。** ボタン/リンクの `href` に使う |
| `{{landing_url}}` | ランディングページ URL | 通常は不要。`{{click_url}}` を優先 |
| `{{open_pixel}}` | 開封追跡ピクセル URL | 任意。「開封を追跡」有効時は自動処理も可 |

### HTML 例

```html
<p>{{email}} 様：</p>
<p>次のリンクから認証を完了してください：</p>
<p><a href="{{click_url}}">今すぐ認証</a></p>
```

### プレーンテキスト例

```text
{{email}} 様：
次のリンクを開いて認証してください：
{{click_url}}
```

### 注意

- `{{click_url}}` はクリック可能なリンクに置いてください。生のランディング URL だけに頼らないでください。  
- 開封追跡は **HTML** メールのみ有効です。  
- メール用プレースホルダーとプロジェクト用ランディングページのプレースホルダーを混在させないでください。

# 佔位符使用說明

在 HTML 或郵件正文裡寫入下方標記後，平台會在部署或發信時自動替換成真實內容。

兩套佔位符互不通用：

- **專案落地頁**裡的標記，不要寫進郵件
- **郵件**裡的標記，不要寫進專案 HTML

頁面庫 / 頁面構建預覽**不會**替換專案佔位符。請在「頁面製作」上傳或鏡像 HTML，新建專案時選擇該頁面，構建/啟動後再生效。

---

## 一、專案落地頁（專案管理）

上傳到專案的釣魚頁 HTML 可使用以下佔位符。

| 佔位符 | 用途 | 填寫建議 |
|--------|------|----------|
| `{{SUBMIT_URL}}` | 表單提交地址 | **建議必寫**，用作表單 `action` 或介面地址 |
| `{{REDIRECT_URL}}` | 提交後跳轉的原始網站連結 | 按需，對應專案裡的「原始連結」 |
| `{{QR_RELAY_URL}}` | 即時二維碼圖片地址 | 需要掃碼展示時使用；須在專案中綁定 QR 中繼 |
| `{{QR_RELAY_IMG}}` | 整段二維碼 `<img>` 標籤 | 同上；寫這一項即可，不必再手寫 `img` |

### 範例

```html
<!DOCTYPE html>
<html lang="zh-Hant">
<head>
  <meta charset="utf-8" />
  <title>登入</title>
</head>
<body>
  <h1>請登入</h1>

  <form method="POST" action="{{SUBMIT_URL}}">
    <input name="username" placeholder="帳號" required />
    <input name="password" type="password" placeholder="密碼" required />
    <button type="submit">登入</button>
  </form>

  <!-- 掃碼登入：先在「QR 釣魚」建立中繼，再在專案中綁定 -->
  <h2>掃碼登入</h2>
  {{QR_RELAY_IMG}}

  <!-- 也可以自己寫圖片標籤：
  <img src="{{QR_RELAY_URL}}" alt="掃碼登入" width="240" height="240" />
  -->

  <p><a href="{{REDIRECT_URL}}">返回官網</a></p>
</body>
</html>
```

### 使用步驟（含二維碼時）

1. 工作台 → **QR 釣魚**：建立中繼，按頁面上的步驟（或 zip 內說明）執行本機截屏腳本上傳畫面  
2. **專案管理**：新建或編輯專案，選擇頁面製作中的頁面，在「QR 中繼」中選擇該中繼  
3. 構建並啟動專案  
4. 用專案存取地址開啟頁面，確認提交地址與二維碼已顯示  

### 注意

- 修改「原始連結」、更換綁定的中繼，或輪換了公開連結後，請**重新構建或重新啟動**專案後再查看效果。  
- 未綁定中繼，或中繼已暫停時，`{{QR_RELAY_URL}}` / `{{QR_RELAY_IMG}}` 會變成空白。  
- `{{QR_RELAY_IMG}}` 本身就是一整段標籤，請單獨成行，不要寫成 `src="{{QR_RELAY_IMG}}"`。

## 二、郵件正文（工作台 → 傳送郵件）

編寫郵件時可使用以下佔位符。發信時會對每個收件人分別替換。

| 佔位符 | 用途 | 填寫建議 |
|--------|------|----------|
| `{{email}}` | 當前收件人郵箱 | 需要稱呼時寫入 |
| `{{click_url}}` | 可追蹤的跳轉連結 | **建議必寫**，用作按鈕或超連結的 `href` |
| `{{landing_url}}` | 落地頁地址 | 一般可不用；優先使用 `{{click_url}}` |
| `{{open_pixel}}` | 開啟統計用的隱藏圖片地址 | 可選；開啟「追蹤開啟」時，不寫也會自動處理 |

### HTML 範例

```html
<p>您好，{{email}}：</p>
<p>請點選下方連結完成驗證：</p>
<p><a href="{{click_url}}">立即驗證</a></p>
```

### 純文字範例

```text
您好，{{email}}：
請開啟以下連結完成驗證：
{{click_url}}
```

### 注意

- 請把 `{{click_url}}` 放在使用者能點選的連結上，不要只寫落地站明文地址。  
- 「追蹤開啟」僅對 **HTML** 郵件有效。  
- 郵件佔位符與專案落地頁佔位符不能混用。

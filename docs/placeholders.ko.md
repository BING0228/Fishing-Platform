# 플레이스홀더 가이드

아래 마커를 HTML 또는 메일 본문에 넣으면, 프로젝트 배포 또는 메일 발송 시 플랫폼이 실제 값으로 치환합니다.

두 세트는 **서로 호환되지 않습니다**:

- **프로젝트 랜딩 페이지** 마커를 메일에 넣지 마세요
- **메일** 마커를 프로젝트 HTML에 넣지 마세요

페이지 라이브러리 / 페이지 빌더 미리보기는 프로젝트 플레이스홀더를 **치환하지 않습니다**. **페이지 제작**에서 HTML을 업로드하거나 미러링하고, 프로젝트 생성 시 해당 페이지를 선택한 뒤 빌드/시작하세요.

---

## 1. 프로젝트 랜딩 페이지(프로젝트)

프로젝트에 업로드하는 HTML에서 다음 플레이스홀더를 사용합니다.

| 플레이스홀더 | 용도 | 작성 안내 |
|--------------|------|-----------|
| `{{SUBMIT_URL}}` | 폼 제출 URL | **권장.** 폼 `action` 또는 API URL로 사용 |
| `{{REDIRECT_URL}}` | 제출 후 원본 사이트 URL | 선택. 프로젝트의 「원본 URL」 필드에서 가져옴 |
| `{{QR_RELAY_URL}}` | 실시간 QR 이미지 URL | 스캔 로그인 UI용. 프로젝트에 QR 릴레이를 바인딩 |
| `{{QR_RELAY_IMG}}` | QR 전체 `<img>` 태그 | 위와 동일. 직접 `img`를 쓰지 말고 이 토큰을 삽입 |

### 예제

```html
<!DOCTYPE html>
<html lang="ko">
<head>
  <meta charset="utf-8" />
  <title>로그인</title>
</head>
<body>
  <h1>로그인</h1>

  <form method="POST" action="{{SUBMIT_URL}}">
    <input name="username" placeholder="사용자 이름" required />
    <input name="password" type="password" placeholder="비밀번호" required />
    <button type="submit">로그인</button>
  </form>

  <!-- 스캔 로그인: QR 피싱에서 릴레이를 만든 뒤 프로젝트에 바인딩 -->
  <h2>스캔하여 로그인</h2>
  {{QR_RELAY_IMG}}

  <!-- 또는 이미지 태그를 직접 작성:
  <img src="{{QR_RELAY_URL}}" alt="스캔하여 로그인" width="240" height="240" />
  -->

  <p><a href="{{REDIRECT_URL}}">공식 사이트로 돌아가기</a></p>
</body>
</html>
```

### 절차(QR 사용 시)

1. 워크벤치 → **QR 피싱**: 릴레이를 만들고 로컬 캡처 스크립트를 실행  
2. **프로젝트**: 생성 또는 편집, 페이지 제작의 페이지를 고르고 「QR 릴레이」에서 해당 릴레이 선택  
3. 프로젝트를 빌드하고 시작  
4. 프로젝트 URL을 열어 제출 URL과 QR 이미지가 렌더되는지 확인  

### 참고

- 원본 URL 변경, 릴레이 재바인딩, 공개 슬러그 교체 후에는 프로젝트를 **다시 빌드하거나 다시 시작**하세요.  
- 릴레이가 없거나 일시 중지된 경우 `{{QR_RELAY_URL}}` / `{{QR_RELAY_IMG}}`는 빈 값이 됩니다.  
- `{{QR_RELAY_IMG}}`는 완전한 태그입니다. 단독 줄에 두고 `src="{{QR_RELAY_IMG}}"`처럼 쓰지 마세요.

## 2. 메일 본문(워크벤치 → 메일 보내기)

캠페인 본문에서 다음 플레이스홀더를 사용합니다. 발송 시 수신자별로 치환됩니다.

| 플레이스홀더 | 용도 | 작성 안내 |
|--------------|------|-----------|
| `{{email}}` | 현재 수신자 주소 | 인사말에 사용 |
| `{{click_url}}` | 추적 가능한 클릭 URL | **권장.** 버튼/링크 `href`로 사용 |
| `{{landing_url}}` | 랜딩 페이지 URL | 보통 불필요. `{{click_url}}` 우선 |
| `{{open_pixel}}` | 열람 추적 픽셀 URL | 선택. 「열람 추적」 사용 시 자동 처리 가능 |

### HTML 예제

```html
<p>{{email}} 님:</p>
<p>아래 링크에서 인증을 완료하세요:</p>
<p><a href="{{click_url}}">지금 인증</a></p>
```

### 일반 텍스트 예제

```text
{{email}} 님:
다음 링크를 열어 인증하세요:
{{click_url}}
```

### 참고

- `{{click_url}}`을 클릭 가능한 링크에 넣으세요. 원시 랜딩 URL만 쓰지 마세요.  
- 열람 추적은 **HTML** 메일에만 적용됩니다.  
- 메일 플레이스홀더와 프로젝트 랜딩 페이지 플레이스홀더를 섞지 마세요.
